The agent

Discover

The Composio SDK searches its tool catalog for each app. Matches are leads only.

Research

Codex CLI searches vendor docs and returns a strict JSON brief. SQLite saves each pass.

Challenge

A second pass re-opens sources and amends claims. A validator rejects missing citations and labels without first-party evidence.

Check

Ten unseen apps are graded against vendor pages. Grades and misses are published below.

What happened in the run

Passes by model: %%MODELS%%. The run began on gpt-6.1-sol, then moved to gpt-6-luna to cut cost. Saved passes with recorded usage read %%INPUT_M%%M input tokens, %%CACHED_PCT%%% cached. %%FAILS%% failures were logged, including %%TIMEOUTS%% timeouts. Failed apps were retried.

Apps without a valid second pass (%%MISSING_COUNT%%): %%MISSING%%. Their rows show the first pass.

Where a human was needed

A person started the run, chose the cheaper model and resumed it after the laptop slept. Grading was done by an AI assistant, so independent human review is still pending. No vendor account was opened and no vendor API was called.

Run it

Node.js 22.13+, a signed-in Codex CLI, the Composio SDK and a project API key.

node research.mjs check && node research.mjs run --mode composio --ids all --workers 4 --run full

Reuse the run name to resume. If the Codex plan limit is hit, the runner waits and retries the same step.
